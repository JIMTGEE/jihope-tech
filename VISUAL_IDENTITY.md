## Typography System

### Heading Font
**Font Family:** Inter Bold / Poppins Bold / Montserrat Bold  
**Use Case:** Headlines, CTAs, brand statements  
**Characteristics:** Geometric, modern, confident, technical

- H1: 48px, bold, Midnight Navy
- H2: 36px, bold, Midnight Navy
- H3: 28px, bold, Electric Blue
- H4: 24px, semi-bold, Charcoal Gray

### Body Font
**Font Family:** Inter Regular / Roboto / Open Sans  
**Use Case:** Body text, descriptions, content  
**Characteristics:** Clean, readable, professional, accessible

- Body: 16px, regular, #333333
- Small: 14px, regular, #666666
- Captions: 12px, regular, #999999

### Code & Technical Font
**Font Family:** Source Code Pro / JetBrains Mono / IBM Plex Mono  
**Use Case:** Code snippets, technical documentation  
**Characteristics:** Monospace, precise, technical

## Logo & Mark Guidelines

### Logo Concept
**Style:** Geometric, minimal, technical  
**Symbolism:** 
- An interconnected circuit or grid pattern
- Forward motion or upward trajectory
- System integration and reliability
- Security/lock symbolism optional

### Logo Variations
1. **Full Logo** - Brand name + mark (primary use)
2. **Mark Only** - Icon/symbol alone (favicon, app icon, social)
3. **Horizontal Layout** - Logo on left, text on right
4. **Vertical Layout** - Mark above, brand name below
5. **Monochrome** - Single color for print/embroidery
6. **Reverse** - White on dark backgrounds

### Minimum Size
- Digital: 120px width
- Print: 0.5 inches width

### Clear Space
Minimum clear space around logo = 1/4 of logo height on all sides

## Visual Style & Design Language

### Photography & Imagery
- **Style:** Clean, professional, technical, modern
- **Color Tone:** Favors cool tones (blues, grays, whites)
- **Content:** Technology, teams working, code, systems, transformation
- **Avoid:** Stock photos of people looking at laptops, generic "tech" imagery
- **Better:** Real screenshots, code, data visualization, authentic team moments

### Icons & Iconography
- **Style:** Minimal, geometric, technical, consistent
- **Weight:** 2px stroke weight for consistency
- **Size:** Designed for 16px, 24px, 32px, 48px
- **Categories:**
  - Service icons (web, mobile, security, etc.)
  - Feature icons (speed, reliability, trust, etc.)
  - Action icons (arrow, check, download, etc.)
  - Social/platform icons

### Graphic Elements
- **Grid System:** 8px base grid for layouts
- **Borders:** 1-2px solid borders in Navy or Silver
- **Shadows:** Subtle, professional (0 2px 8px rgba(0,31,63,0.1))
- **Patterns:** Minimal geometric patterns, never overwhelming
- **Accents:** Use Electric Blue for highlights and CTAs

## Brand Voice & Tone

### How We Communicate

**Professional** - Industry expertise, authoritative, strategic  
**Trustworthy** - Clear, honest, transparent, accountable  
**Reliable** - Consistent, dependable, thorough  
**Innovative** - Forward-thinking, solution-focused, adaptive  
**Direct** - No buzzwords, no fluff, cut to value  

### Language Guidelines

✅ **DO:**
- Use active voice: "We transform systems" not "Systems are transformed"
- Be specific: "Secure cloud migration with zero downtime" not "Cloud solutions"
- Focus on client outcomes: "Your business runs 40% faster" not "We use fast technology"
- Use numbers and proof: "Deployed 25+ systems" not "Many systems"
- Be humble: "We've learned..." not "We're the best..."

❌ **DON'T:**
- Use industry jargon without explanation
- Make vague promises: "Next-gen solutions," "cutting-edge," "synergy"
- Use superlatives: "World-class," "best," "leading" (show, don't tell)
- Be overly casual in professional contexts
- Exaggerate or oversell capabilities

### Tagline Options (Ranked)

1. **"Engineering Reliable Digital Transformation"**  
   - Clear, professional, outcome-focused
   
2. **"Solve. Deliver. Transform."**  
   - Action-oriented, memorable, three-part promise
   
3. **"Building Systems You Can Trust"**  
   - Emphasizes reliability and integrity
   
4. **"Technology Built for Real-World Impact"**  
   - Outcome and purpose-driven
   
5. **"Reliable. Secure. Transformative."**  
   - Core values in one line

**Recommended Primary Tagline:** "Engineering Reliable Digital Transformation"
